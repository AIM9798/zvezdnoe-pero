# Академия Звёздного Пера

Мобильная 3D-игра про магический город на летающих островах. Движок Unity 6.3 LTS (URP), платформа Android.

Браузерный прототип остаётся эталоном механик, а код пишется заново здесь. План переноса и этапы лежат в документе «План переноса в Unity и выпуска на Android».

## Как открыть проект (первый раз)

1. Поставь [Unity Hub](https://unity.com/download), а в нём Unity **6000.3 LTS** с модулем **Android Build Support** (галочки OpenJDK и Android SDK & NDK тоже).
2. Скачай репозиторий: зелёная кнопка **Code → Download ZIP** или GitHub Desktop → Clone.
3. В Unity Hub выбери **Add → Add project from disk** и укажи папку репозитория. Если Hub предложит другую версию 6000.3, соглашайся.
4. Первое открытие идёт 5–15 минут: Unity скачивает пакеты (URP, glTFast, Input System) и импортирует модели.
   - Если Unity спросит про **новую систему ввода (Input System)**, нажми **Yes**. Редактор перезапустится.
   - Если пакет выдаст ошибку версии, открой **Window → Package Manager**, выбери этот пакет и нажми **Update**.
5. В верхнем меню **Звёздное перо**:
   1. **1. Настроить проект (Android, URP, ввод)** настраивает Android (64-bit, IL2CPP, Android 8+), URP и ввод.
   2. **2. Собрать стартовую сцену** собирает сцену `Assets/_Project/Scenes/Main.unity`.
   3. **3. Собрать тестовый APK** собирает файл `Builds/Android/zvezdnoe-pero-test.apk`. Его можно скинуть на телефон и установить.
6. Открой сцену Main и нажми **Play**.

### Управление

| На телефоне | В редакторе |
|---|---|
| Джойстик слева | WASD |
| Свайп справа — камера | Правая кнопка мыши + движение |
| «Метла» — сесть или слезть | F |
| «Прыжок/вверх», «Вниз» | Пробел, Ctrl |
| «Действие» — войти или поговорить | E |

## Что уже есть

- **Большая карта**, около 600 × 600 м, из пяти островов:
  - Лунный Перекрёсток;
  - Академия;
  - Жилой берег;
  - Туманные Рубежи (туда можно попасть только на метле);
  - Облачная гавань.
  Острова соединены мостами.
- **Реальный масштаб**: игрок ростом 1,7 м, дверь 2,5 м, этаж 3,5 м. Дома в 2–3 этажа, замок с башней 45 м, Зельеварня 28 м.
- **Твои модели** из Pixellab (текстуры сжаты до 1024 px):
  - башня мага стала Зельеварней;
  - две каменные башни стоят у Академии;
  - кот-жнец стал NPC «Кот-Хранитель Мрак» с процедурной анимацией: парит, ходит вперевалку, здоровается, крутится, «читает».
- **Персонаж и метла**: ходьба и прыжок, полёт на метле со скоростью 15 м/с (через всю карту примерно за 40 секунд). Если упасть с острова, персонаж возвращается на последнюю точку, где стоял.
- **Камера** следует за персонажем, поворачивается свайпом и не проходит сквозь стены.
- **Двери** у всех зданий: показывают подсказку «Войти». Интерьеры появятся на этапе «Механики».
- **Названия островов** показываются при входе в каждый район.

Всё, кроме трёх моделей, пока серые заготовки (greybox). Художники заменяют их своими моделями, а скрипты и разметка остаются.

## Структура

```
Assets/_Project/
  Art/Models/          GLB-модели (импорт через glTFast)
  Scripts/Runtime/     игровой код: Player, Input, CameraRig, World, Creatures, UI
  Scripts/Editor/      меню «Звёздное перо»: настройка проекта, сборка сцены и APK
  Scenes/ Materials/ Generated/ Settings/   создаются меню на твоём компьютере
```

Модели добавляются так: положи `.glb` в `Assets/_Project/Art/Models/`, и Unity импортирует его сам. Лимиты по треугольникам и текстурам есть в плане переноса, в разделе «Арт».

## Ключи и подпись

Ключ подписи Android (`.keystore`), ключи Photon и Unity Gaming Services **не коммитим**: они уже добавлены в `.gitignore`. Ключ подписи хранится только у владельца проекта.
