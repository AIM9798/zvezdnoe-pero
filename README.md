# Звёздное перо

Мобильная 3D-игра про магический город на летающих островах (Android, Unity).

Репозиторий построен на шаблоне [Claude Code Game Studios](docs/studio/README.md): агенты студии (арт-директор, геймдизайнер, Unity-специалист и другие) и навыки в `.claude/` работают, когда Claude Code открыт в папке этого репозитория.

Лицензия шаблона студии (MIT): [docs/studio/LICENSE](docs/studio/LICENSE). Сама игра и её ассеты не входят в эту лицензию.
